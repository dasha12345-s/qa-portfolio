# Saucedemo Full Suite

![Cypress Tests](https://github.com/dasha12345-s/QA-PORTFOLIO/actions/workflows/cypress.yml/badge.svg)

## Project Overview
This is a professional Cypress E2E test suite for **saucedemo.com**. 
It demonstrates advanced testing concepts including:
*   **Page Object Model (POM)** for clean, maintainable selectors.
*   **API Intercepting & Stubbing** for testing edge cases and "Problem User" bugs.
*   **Data-Driven Testing (DDT)** using JSON fixtures.
*   **CI/CD Integration** with GitHub Actions and artifact reporting.

## How to Run
1. `cd saucedemo-full-suite`
2. `npm install`
3. `npx cypress open`
